# Annecy–Alpes–Léman v0.3 — recherche

Cette branche prépare une future évolution du pack Annecy–Alpes–Léman sans modifier la version publiée **v0.2**, qui reste figée à 65 mémoires / 48 sans aviation.

## Objectif du chantier secours / ADRASEC

Le périmètre évolue peu par rapport à v0.2. Le principal complément consiste à réexaminer les relais et transpondeurs radioamateurs utilisés ou prioritaires pour les ADRASEC dans les départements 74, 73, 38 et 01.

Premiers cas :

- `F1ZJV` — Pointe des Brasses — relais VHF analogique ADRASEC 74 ;
- `F1ZYT` — Semnoz — même fréquence de sortie VHF que F1ZJV, avec fonctions ADRASEC ;
- `F1ZHG` — Fort du Mont — transpondeur ADRASEC 73 ;
- autres relais ADRASEC 73/38/01 uniquement si leur couverture est réellement pertinente pour le bassin Annecy–Léman.

Une même fréquence de sortie ne sera pas dupliquée uniquement pour représenter deux sites différents. Les sites et rôles ADRASEC pourront rester dans les métadonnées.

Les réseaux professionnels privés de secours ne sont pas ajoutés comme canaux d'écoute simplement parce qu'ils existent.
